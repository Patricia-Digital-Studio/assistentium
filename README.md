# ASSISTENTIUM – Website-Prototyp

Klickbarer Prototyp für den Relaunch von assistentium.de (Joomla → WordPress/Divi, Launch Januar 2027).

**Stand:** 29.10.2026 · Startseite und Unterseite Schulbegleitung (`#schulbegleitung`)

## Inhalt

- `index.html` – der Prototyp, eine Datei, ohne Build-Schritt
- `assets/` – Logo, Platzhalterfotos, KOMPASS-Material
- `robots.txt` + `noindex` – die Seite soll nicht in Suchmaschinen auftauchen

## Hinweise

- Gestreifte Flächen und das Hero-Foto (Pexels) sind Platzhalter.
- Der Imagefilm ist per Zwei-Klick-Lösung über youtube-nocookie.com eingebunden: Vor dem Klick werden keine Daten an YouTube übertragen.
- Logo und KOMPASS-Bilder stammen aus Screenshots, für den Livegang werden die Originaldateien benötigt.
- Telefonnummern der Ansprechpartnerinnen sind bewusst Platzhalter.

## Ansehen

Über GitHub Pages: Settings → Pages → Branch `main`, Ordner `/ (root)`.
